实战教程：3步轻松在线抠图并导出透明底PNG

难度：入门小白 • 耗时：2 分钟 • 输出格式：透明 PNG
随时随地，纯浏览器极速抠图
零依赖，零插件，打开即用。
打开 Web PSEditor 开始抠图 →

制作电商商品图、PPT 配图或专属表情包时，提取纯净透明的主体是最高频的需求。传统的 JPG 格式不支持透明度，必须将背景彻底剥离并保存为 PNG 格式。下面教你用 Web PSEditor 快速抠图的实用工作流。

第一步：导入并解锁基础图层

打开 Web PSEditor，将图片拖入画板。右侧图层面板（Layers）会默认生成一个基础图层。确保右侧图层处于选中状态（点击图层高亮）。

第二步：使用魔棒或多边形套索精准圈定背景

针对纯色/简单背景：点击左侧 魔棒工具，点击背景区域，配合顶部 容差（Tolerance） 微调即可完整框选背景。
针对复杂背景：推荐使用 套索工具（Lasso） 或 多边形选区，沿着主体边缘打点圈出轮廓。

第三步：一键清除背景并无损保存为 PNG

选区建立完成后，直接按下键盘的 Delete（或 Backspace）按键，背景瞬间被擦除！此时背景会呈现经典黑白灰的棋盘方格纹理（代表绝对透明）。
点击 【文件】 -> 【另存为】，**务必选择 PNG 格式**（JPG 不支持透明背景，存为 JPG 背景会自动变白）。

💡 为什么我的背景存下来还是白色？
请务必检查导出时的格式设置。JPG 图片协议本身没有 Alpha 透明通道，只有 **PNG** 或 **WebP** 才能完美保留抠出来的透明图层！

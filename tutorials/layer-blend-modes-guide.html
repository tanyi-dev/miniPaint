三大最常用混合模式速记指南：

• 正片叠底（Multiply）：过滤白色、保留暗色。常用于把白底线稿、白底签名快速融入背景，免去抠图烦恼！
• 滤色（Screen）：过滤黑色、保留亮色。常用于给照片叠加星光、光斑、火焰、烟雾等黑色背景特效素材！
• 叠加 / 柔光（Overlay / Soft Light）：增强对比度与氛围感。常用于将复古纹理纸张或光影质感无缝贴合在画面上。

实操演练：把黑底光斑特效合成到人物照片上

1. 打开人物底图。
2. 点击顶部菜单 【图层 (Layer)】 -> 【新建图层 (New Layer)】，或直接拖拽一张带有炫酷光斑的黑底图片进画布。
3. 在右侧图层面板选中光斑图层，将混合模式（Composition Mode）由 Source-Over (正常) 改为 Screen (滤色)。
4. 黑色背景瞬间消失，璀璨的光斑自然融入人像之中，电影感大片一秒生成！

Remove a Small Object With the Clone Tool

By Web PSEditor • Difficulty: Intermediate • 7 min read • Updated: 13 Nov 2026
Sample, then paint
Right-click sets the source point; the Clone tool copies pixels under the brush.
Open Web PSEditor & Clone →

A cable across a wall, a bin in the corner of a product shot, a bit of litter on the grass. Small distractions that no crop can fix. The Clone tool handles these by copying pixels from one part of the layer to another, and it has two behaviours that catch first-time users out: the source must be set with a right-click, and the layer has to be an untouched raster.

How the Tool Actually Works

Right-click to place the source

Select the Clone tool in the left toolbar, then right-click on the area you want to copy — clean wall, plain grass, uninterrupted sky. A confirmation appears that the source coordinates are saved. A long press on touch devices does the same thing.

Then paint over the object

Left-click and drag across the thing you want gone. The pixels under the brush come from the saved source, offset by the distance between the source point and where you started painting. That offset stays constant for the stroke, which is why short strokes work better than long ones.

Reset the source often

After each short stroke, right-click a fresh area. A single long stroke drags one band of texture across the whole frame and leaves a visible streak — the most common clone-tool tell.

Requirements the Tool Enforces

ConditionWhat happens if not met
Layer contains a raster imageError asking you to convert the layer to raster first
Layer has not been resized"Clone tool disabled for resized image" — rasterize first
Layer is not rotatedError asking you to rasterize the rotated object
Source coordinates saved"Source is empty, right click on image" message

That second row matters in practice: if you resized the image with Image → Resize, clone can refuse until the layer is rasterised with Layer → Convert to Raster. Rasterising is one-way, so do any resize last if you plan to clone.

Source Layer: Current or Previous

The tool's options include a source layer setting. Current samples from the layer you are painting on. Previous samples from the layer directly below — useful when you want to repair a photo on one layer while keeping the original untouched underneath: paint the repair on the top layer, and if it goes wrong, delete that layer instead of undoing twenty strokes.

What It Can and Cannot Remove

  • Works: a cable on a plain wall, a small bin on grass, a watermark-free logo on a uniform background, a hair or dust speck on a scan.
  • Works with care: a person at the edge of a group, a sign on a textured wall — every stroke needs a new source from the same texture.
  • Fails: anything crossing a straight line, a face, text, or a strong gradient. The clone copies the source's structure, so a horizon will bend and a gradient will band.
  • Fails badly: large objects. Covering a third of the frame needs dozens of strokes and the texture repetition becomes obvious.

Techniques That Look Clean

Work from the edges inward

Repair the boundary between object and background first, using sources that sit just outside the object. Then fill the middle. Doing it the other way leaves a halo of the original object around a repaired centre.

Match the texture direction

On grass, wood or brick, the texture has a direction. Pick a source that runs the same way: cloning vertical brick lines into a horizontal course produces a visible cross-hatch.

Keep the brush soft but not too soft

A hard edge repeats the seam of the clone stamp; an extremely soft brush smears a blur into the area. A medium-hard round brush, small relative to the object, gives the least obvious result.

Check at 100%, then step back

Clone marks are invisible when you are staring at the cursor and obvious when you look at the whole frame. Alternate between 100% and fit-to-window every few strokes.

When Cloning Is the Wrong Tool

For a large area of texture — a whole wall, a stretch of sky — Tools → Content Fill extends the edges in one operation and does a better job than fifty clone strokes. For a face or a person, hide rather than remove: Effects → Mosaic or Gaussian Blur is the honest approach, and it is what privacy redaction needs anyway. Cloning a person out of a photo is fabrication, and it shows.

💡 Right-click to set the source, paint in short strokes, reset the source constantly, and rasterise before resizing. Big areas belong to Content Fill, not to the clone stamp.

Quick Answers

The Clone tool says the source is empty. What did I miss?

The source point has to be saved with a right-click (or a long press on touch) on the area you want to copy before the first stroke. Left-clicking alone only paints with no source, which produces the error message.

Why is the Clone tool disabled on my image?

The layer has probably been resized or rotated. Convert it with Layer → Convert to Raster, or undo back to the original size and clone before resizing. The tool refuses to work on scaled layers because the source coordinates would map to the wrong pixels.

How do I avoid the repeating pattern that gives cloning away?

Use short strokes and reset the source point after each one, sample from different areas with the same texture direction, and alternate between 100% zoom and fit-to-window while working. If a large area needs repair, use Tools → Content Fill instead of many clone strokes.

Remove High-ISO Noise Without Wrecking Detail

By Web PSEditor • Difficulty: Beginner • 7 min read • Updated: 13 Nov 2026
Grain or mush — the choice is one number
Effects → Denoise, Exponent 0–50, default 20. Lower than you think.
Open Web PSEditor & Denoise →

Every phone photo taken indoors after dark has the same problem: colour speckles in the shadows and a sandy texture across flat areas. It comes from the sensor amplifying a weak signal, and it is worst exactly where photos are judged — shadows, skin, plain walls.

Effects → Denoise offers a single control, Exponent, from 0 to 50 with a default of 20. Higher values smooth more. There is no separate luminance and colour control here, so the whole job is picking the point where the grain disappears before the texture does.

What the Exponent Actually Trades

ExponentGrainDetail leftUse for
5–10Reduced slightlyAlmost allMild grain on a well-lit photo
10–20Most of the visible speckle goneTexture intactThe safe default for phone night shots
20–30Clean flat areasFine hair and fabric start to mergeFlat backgrounds, product shots, sky
30–50PlasticPores, stitches and eyelashes goneRarely. Only for a small area that must be clean

The default of 20 is not a neutral starting point; it is already a strong setting on a 24 MP file viewed at 100%. Start at 10, compare, and only climb if the grain is still obvious at the size the image will be seen.

Order: Denoise, Then Everything Else

Denoise before sharpening

Sharpen amplifies local contrast, which includes noise. Sharpen a noisy file and the grain becomes clumps with hard edges. If you already sharpened, the damage is baked in — undo before denoising, do not try to fix it after.

Denoise before resizing down

Downscaling partially averages noise away on its own. For a 4000 px file going to 1200 px, resize first and you may not need to denoise at all. Do it in the other order and you smooth a file that was about to be smoothed anyway, losing detail for nothing.

Denoise after colour correction, not before

Correcting exposure upwards brightens the shadows and makes noise more visible, so the amount you need becomes clearer after the correction. Pull the shadows up first with Image → Color Corrections, then judge how much denoise the image actually needs.

Keeping Texture Where It Matters

Global denoise treats a portrait's cheek and a plain wall the same way, which is why faces end up looking like wax. There is no mask tool here, but the layer stack does the job:

Denoise a copy, then re-reveal the detail

Duplicate the layer (Layer → Duplicate), denoise the copy at the value that cleans the background, then take a soft Eraser and wipe the copy over eyes, hair, lips and any texture you want back. The untouched layer underneath shows through. Result: clean background, real skin.

Denoise the colour, not the edges

Colour speckles in shadows are more objectionable than luminance grain, and they are also easier to remove without hurting structure. If the image only has colour blotches, a moderate exponent fixes the complaint and leaves edges alone. If the grain is luminance (grey sandy texture), it is structural — go lower and accept some grain.

Signs You Went Too Far

  • Skin has no pores and reads like plastic, especially on foreheads and cheeks.
  • Hair merges into a single mass with no individual strands at the edge.
  • Fabric texture is gone — knitwear becomes a flat colour field.
  • Edges look painted, with a slight watercolour bleed along high-contrast boundaries.

All four are irreversible once exported, and all four are more noticeable than the noise they replaced. A slightly grainy photo looks like a photo; a plastic one looks like a bad filter.

Noise You Should Not Remove

Film grain in a scanned photograph is part of the image, not a defect. Denoising it flattens the tonal transitions that make the scan look photographic. The same goes for texture that carries information: sand, fabric weave, wood grain, brushed metal. If the grain is uniform across the whole frame and looks intentional, leave it.

💡 Start at Exponent 10, not 20. Denoise before sharpen and before downscaling, and denoise a copy so you can erase the effect off faces.

Quick Answers

What exponent should I start with?

Ten, not the default twenty. At 20 on a large file viewed at 100% the effect is already strong. Start at 10, look at the shadow areas at 100% zoom, and increase in steps of five only if grain is still obvious at the final viewing size.

Why does denoising make faces look like plastic?

Because it smooths skin texture along with noise, and skin is mostly fine texture. Denoise a duplicated layer instead, then erase that layer over eyes, hair and cheeks so the original texture shows through. Background stays clean, faces keep their detail.

Does denoising recover detail in a noisy photo?

No, it only removes information. Noise reduction trades texture for smoothness, so it never adds anything. That is why the order matters: denoise before sharpening, and skip it entirely when downscaling already averages the grain away.

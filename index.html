Frequently Asked Questions (FAQ)

Learn about Web PSEditor safety, compatibility, and browser capabilities

Does Web PSEditor upload my images to any server?
Never. All processing, layers, and filters run locally inside your browser Canvas. Zero server uploads, safeguarding your confidential images.
Can I use all editing features on mobile phones?
Mobile browsers can view tutorials and UI, but for precision selection, shortcuts, and multi-layer work, desktop browsers with keyboard and mouse are recommended.
Are there any watermarks or resolution limits upon export?
100% free with no watermarks and no resolution caps. Supports exporting lossless PNG, JPEG, and WEBP.
Which image formats are supported for import and editing?
Supports major raster formats including PNG (alpha transparency), JPEG, WEBP, GIF, BMP, SVG, and multi-layer JSON project files.
Are shortcuts consistent with standard professional image editors?
Standard shortcuts are closely aligned: Ctrl+Z (Undo), Ctrl+Y (Redo), Ctrl+C/V (Copy/Paste), Space+Drag (Pan canvas), and Scroll wheel (Zoom).

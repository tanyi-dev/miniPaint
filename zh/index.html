常见问题解答 (FAQ)

了解 Web PSEditor 的安全性、平台兼容性与使用细节

Web PSEditor 会将我的照片上传到服务器吗？
绝不。所有图像渲染、裁剪、滤镜均运行在浏览器本地 Canvas 环境，零数据交互，绝对保护财务与证件隐私。
手机端可以使用全部修图功能吗？
手机端可浏览所有教程与参数，但为了保证精细化的选区和图层体验，建议在 PC 电脑浏览器中使用键鼠操作。
导出图片有水印或分辨率限制吗？
完全无水印、不限制分辨率，支持无损导出 PNG、JPG 及 WEBP。
支持哪些图片格式的导入与编辑？
支持导入主流光栅图片格式，包括 PNG（保留透明度）、JPEG/JPG、WEBP、GIF、BMP、SVG 等，还支持多图层 JSON 工程文件的保存与再次导入编辑。
常用的修图快捷键与其他专业图像编辑软件一致吗？
常用快捷键高度习惯对齐：Ctrl+Z（撤销）、Ctrl+Y（重做）、Ctrl+C/V（复制粘贴）、Space+拖拽（平移画布）、滚轮（缩放），支持快速盲操与高频精修。

准备好开始你的图像创作了吗？

零安装、零等待、100% 浏览器本地运算。所有图片绝不上云，安全可靠。

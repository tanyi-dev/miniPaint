关于 Web PSEditor

最近更新日期：2026年10月2日

Web PSEditor 是一款完全在浏览器中运行的免费在线图片编辑器。打开照片，用图层、选区、滤镜与文字完成精修，然后直接导出成品——无需安装软件、无需注册账号，更无需把文件交给任何服务器。

一句话说明： 它拥有接近桌面级软件的专业光栅编辑能力，像本地程序一样保护你的隐私，而你只需要一个浏览器标签页。

1. 为什么做这个工具

市面上大多数"免费在线修图"工具的运作方式是：先把你的照片上传到远程服务器，在服务器上处理完，再把结果传回给你。这种模式确实方便，但它隐含了一个前提——你愿意让别人的服务器保管你的文件。对于证件照、护照扫描件、已签字的合同、医疗记录或尚未公开的产品图来说，这个前提很难接受。

Web PSEditor 的设计目标就是彻底去掉这个前提：所有处理都由你自己的设备、在你已经打开的这个浏览器标签页里完成。

2. 核心原则：图片永不离开你的设备

整条处理链路——图片解码、画布渲染、图层合成、滤镜运算、文件导出——全部基于 HTML5 Canvas 与 JavaScript 在本地执行。我们这边没有上传接口、没有处理队列，也没有任何形式的图片存储。

  • 图片从不上传，因此不存在被截获、留存或转售的可能。
  • 无需注册、无需邮箱、无需账号，打开页面即可直接使用。
  • 因为运算是本地的，即使在网速很差的网络环境下，操作依然流畅跟手。
  • 刷新或关闭页面，内存中的内容会被立即释放。

3. 浏览器里能完成哪些工作

Web PSEditor 并非一堆零散滤镜的拼装，而是完整的图层编辑引擎。常见使用场景包括：

  • 抠图与精修——魔棒选区、智能蒙版与背景去除，适用于产品图或证件照制作。
  • 图层合成——支持多图层、混合模式、不透明度、层序与显隐控制。
  • 色彩与影调——亮度、对比度、色相/饱和度、曲线式调整以及一键滤镜预设。
  • 几何变换——裁剪、旋转、倾斜校正、翻转、缩放与画布扩展。
  • 标注与打码——文字、水印、马赛克与模糊，用于遮盖敏感信息。
  • 导出——无损导出 PNG、JPG、WEBP 并可调节压缩质量，也可将整个工程保存为多图层 JSON 文件以便日后继续编辑。

如果你是第一次使用，教程中心按流程逐步讲解了每一项工作流。

4. 谁在使用 Web PSEditor

  • 注重隐私的用户——制作证件照、签证照、扫描件等不应离开个人设备的图片。
  • 师生群体——在学校电脑或 Chromebook 上需要快速修图，且无法安装任何软件。
  • 小微商家——预算有限，却需要制作商品图、横幅与社媒配图。
  • 设计师与开发者——在日常流程中需要快速裁剪、转格式与打码的轻量工具。
  • 使用受限设备或低配置电脑的用户——安装完整桌面版修图软件并不现实。

6. 网站如何保持免费

Web PSEditor 没有订阅制、没有付费墙，导出的图片也不带任何水印。服务器与带宽成本，通过接入 Google AdSense 等第三方广告网络的展示广告来覆盖。

由于您的图片从不上传，广告投放从技术链路层面就与您的图片内容无关——广告仅依据 Cookie 与一般浏览行为进行匹配。完整的数据处理说明请见 隐私政策。

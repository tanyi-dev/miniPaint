隐私政策

最近更新日期：2026年9月20日

欢迎使用 Web PSEditor（在线图像编辑工具）。我们高度重视并严格保护每一位用户的个人隐私安全。本隐私政策详细说明了您在使用我们网站时的数据保护机制。

核心安全承诺： Web PSEditor 是 100% 纯客户端运行的 Web 应用。所有图片处理、图层合成、滤镜渲染及文件导出均直接在您的浏览器中完成，我们绝不会、也无法将您的任何图片上传或保存至任何远程服务器。

1. 本地图像数据安全

当您将照片导入到 Web PSEditor 中时，浏览器通过 HTML5 Canvas 本地 API 进行内存运算，不发生任何网络传输。您的文件在任何环节均不离开您的设备，关闭或刷新页面后，内存自动释放，绝对保障您的商业资产与个人肖像隐私。

2. Cookie 与本地存储的使用

为向您提供连续且稳定的使用体验，本站会使用轻量级 Cookie 及浏览器的 LocalStorage：

  • 偏好记忆： 记录您选择的界面语言（如中文/英文）以及画布常用网格标尺设置。
  • 免登录存储： 所有配置仅在您的设备本地生效，我们不建立任何用户个人账户中心。

3. Google AdSense 广告与第三方服务

本网站可能会接入由第三方广告网络（包括 Google AdSense）提供的展示广告，以维持网站的免费运营与服务器带宽开销：

  • 第三方供应商（包括 Google）会使用 Cookie（例如 DoubleClick Cookie）根据用户以往对本网站或其他网站的访问历史来投放个性化广告。
  • 您可以随时访问 Google 广告设置中心 选择停用个性化广告。
  • 您也可以通过访问 www.aboutads.info 选择停用第三方供应商用于个性化广告的 Cookie。

4. 匿名访问统计

为保障全球访问速度及防御恶意网络攻击，本站使用了 Cloudflare 的边缘网络。Cloudflare 可能会收集标准的网络请求诊断信息（如 IP 地址、浏览器指纹、请求标头），用于网络路由优化与防 DDoS 攻击，此类数据完全为匿名技术聚合日志，不与个人身份关联。

5. 适用法律与合规（GDPR & CCPA）

根据欧盟通用数据保护条例（GDPR）与美国加州消费者隐私法案（CCPA），由于我们不收集、不存储、不贩售任何个人身份信息（PII）与用户原图，您享有天然的数据安全保障。

6. 联系我们

如果您对本隐私政策有任何疑问、意见或反馈，欢迎通过电子邮箱联系我们：support@webpseditor.com。

实战教程：如何在线给图片添加文字水印，防止被盗用

难度：极简入门 • 阅读：8 分钟 • 更新：2026-11-13
图片不上传，水印本地加
纯浏览器 Canvas 处理，素材不出你的电脑。
打开 Web PSEditor 加水印 →

水印挡不住盗图。这句话得先说清楚，否则后面全是空谈。一张图被搬走之后，水印能做的事只有两件：让看到的人知道出处，让搬运的人多花几分钟。前者关乎署名，后者关乎成本。真正决定效果的不是水印有多重，而是它压在画面的什么位置——放在四个角的水印，是最容易被一刀裁掉的那种。

先看效果：处理前 vs 处理后

为什么位置比不透明度重要

先说一个容易被忽略的事实：绝大多数盗图不是精心策划的，而是一次右键保存。这类人不会去修图，看到角标就直接裁掉——裁一刀的成本，比重新拍一张低太多。

所以水印的设计目标不是「无法去除」，那不存在；而是「去掉的代价高于重拍」。压在纯色天空上的字，用内容识别填充几秒钟就能补好；压在主体边缘、纹理、人脸附近的字，抹掉之后那块区域会留下明显的修补痕迹，一看就不对。同样的文字、同样的透明度，位置换一下，防盗效果差一个量级。

不透明度当然也重要，但它解决的是另一个问题：让水印既看得见又不抢画面。这两件事分开处理，思路就清楚了——位置决定防盗，透明度决定观感。

第一步：打开编辑器，导入图片

打开 Web PSEditor，点 【文件】→【打开】 选择照片，也可以直接把文件拖到画布上。导入后右侧是图层面板——后面每一个文字水印都会独立成为一个图层，这一点很关键：改透明度、改位置、单独删掉某一个，都靠它。

第二步：单个署名水印（适合摄影作品、个人博客）

1. 选左侧工具栏的文字工具，在画布上点一下要放水印的位置。
2. 输入署名，例如 摄影 你的名字。文字工具默认是 40 号 Arial、绿色填充，两个都要改：颜色换成白色或浅灰，字号按画面宽度算，取图宽的 3%~5%。手机屏幕只有几英寸宽，小于 3% 的字看不清，只是给画面加了一层灰。
3. 在文字参数里加一像素的深色描边，然后把图层不透明度调到 60%~70%。描边这一步别省，理由在下一节。
4. 需要倾斜就选中文字图层，打开 【图片】→【旋转】。这里的角度框只接受 0~360，想要 -8° 就填 352；直角下拉必须留在「自定义」，选了 0/90/180/270 它会把你的角度直接覆盖掉。确认之后画布会变大以容纳旋转后的图层，用裁剪工具裁回原画幅即可。

第三步：平铺网格（商业图、样片交付必用）

单个水印离边缘够近，一刀就没。铺满画面则把「去掉」从裁剪变成了修图，成本完全不同：
1. 按上一步做好第一个文字图层。
2. 选中它，【图层】→【复制】，把副本拖到下一个位置，重复到覆盖全图。横幅照片铺 6~9 个就够，再多会糊成一片。
3. 全部摆好后，把每个水印图层的不透明度统一降到 30%~40%。低于 30% 时，杂乱背景上的字会直接消失，白铺。
4. 间距要对齐，别靠眼睛拖。定一个位移值（例如每次沿对角线移动 250 像素），每次都移动同样的距离，行与行才对得上。这个编辑器没有按住 Shift 锁定方向的层拖拽，靠固定数值比靠手感稳。

第四步：导出成品

点 【文件】→【导出】，选 JPG（质量 85 以上）或 PNG（需要透明背景时）。
这里有个必须先讲清的坑：【文件】→【另存为】存的不是图片，而是一个带所有图层的 JSON 工程文件，用来下次继续编辑。想拿到能发布的图片，只能走「导出」。
另外，导出的图会把水印直接烧进像素；工程文件里水印仍是可编辑图层。所以建议保留一份分层工程，另外导出一份成品去发布。

放在哪里：三条就够

位置是整件事的核心，因为别人拿到图的第一件事就是重新取景。三条规则覆盖绝大多数情况：

  • 离边至少 3% 宽度。 平台缩放、圆角裁切、封面适配都会吃掉边缘的几个像素，贴边的字最先消失。
  • 压住东西。 天空、白墙、纯色底上的字，一分钟就能克隆掉；压在主体轮廓、商品边缘、有纹理的地面上，抹掉必然留疤。
  • 用对角线。 放两个就放对角，想裁掉其中一个，必然要切到画面中间的主体。

既看得清，又不毁照片

失败的水印通常走两个极端，方向正好相反。一种是淡到看不见：20% 的白色字压在浅色天空上，手机上看就是一层雾，署名作用为零。另一种是重到遮图：字比照片还抢眼，图片成了水印的背景板。

可行的中间值是浅色字配深色描边，整体 50%~70% 不透明度。描边做的是透明度做不到的事——纯白字在亮部消失，纯黑字在暗部消失，而带描边的字在两种背景上都还有一条边。所以先定描边，再调透明度，顺序反了会来回改。

还有一点关于平铺网格的实测经验：30%~40% 的不透明度在编辑器里看着刚好，上传到社交平台后会显得更重。原因是平台重新压缩时，文字边缘会被锐化，局部对比度被拉高。建议先用同套参数导出一张，在手机上看一眼，再批量套用。

⚠️ 四个常见错误
  • 把「另存为」当成导出。 得到的是 JSON 工程文件，打不开、发不了，这是新手最容易卡住的一步。
  • 只用白色不加深色描边。 亮背景上的水印会直接消失，甲方验收时才发现。
  • 角标贴着画框边。 平台缩放时最先被裁掉，等于没加。
  • 旋转时没注意直角下拉。 下拉不是「自定义」时，输入的角度会被覆盖成 90 的倍数，怎么调都是歪的直角。
💡 一条口诀：浅色字、深描边、六成透明度、压住主体。 能被裁掉的水印只是装饰，不叫保护。

常见问题 FAQ

水印怎么做到看得清又不毁图？

浅色字加一像素深色描边，不透明度 60%~70%。描边负责在亮部和暗部都留出一条边界，纯白字会消失在天空里，纯黑字会消失在阴影里。字号比不透明度更重要：不足画面宽度 3% 的字在手机上只是一层噪点。

水印放角落够用吗？

个人作品够用，但要离每条边至少 3% 宽度，否则平台缩放时会被裁掉。商业图不够：别人裁一刀就没了。至少压住主体，或者用对角两个角标，裁掉一个必然裁到内容。

文字水印能被去掉吗？

能。压在纯色背景上的字，用内容识别几分钟就能涂掉。目标不是做一个去不掉的水印——那不存在——而是让去掉的代价大过重新拍一张。压在主体上、铺满细节区域，就是在抬高这个代价。

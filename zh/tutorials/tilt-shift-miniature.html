做出结果可预期的微缩效果

难度：中级 • 阅读：4 分钟 • 更新：2026-11-13
照片决定成败，滑杆只负责收尾
【特效】→【视角移位】：一条清晰带、一层渐变，加饱和与锐化。
打开 Web PSEditor 试视角移位 →

微缩感不是靠模糊做出来的。它靠的是一张从高处俯拍的照片——大脑默认这种视角下一切都该是清楚的——再把除了一条带以外的区域模糊掉。模糊只是确认了构图已经埋好的预期。同一个滤镜套在平视的人像上，你只会得到一张上下糊掉的人像。

【特效】→【视角移位】 把整套机制摊成七个数字，全部带实时预览。搞清楚每个数在干什么，就能从「乱拉滑杆」变成可复现的参数。

七个参数

控件范围 / 默认作用
模糊半径0–30，默认 10失焦区糊到什么程度
渐变半径40–100，默认 70清晰与模糊之间的过渡有多宽
X 起点 / Y 起点各 0–100，默认 0 / 50清晰带的一端，按画布百分比计
X 终点 / Y 终点各 0–100，默认 100 / 50清晰带的另一端
饱和度0–20，默认 3色彩浓度。微缩场景颜色更鲜艳，玩具感更强
锐化0–5，默认 1带内的锐度，和外面的模糊形成反差

这条带是 (X 起点, Y 起点) 到 (X 终点, Y 终点) 的一条线，坐标用百分比。水平的带就是 (0, 50) → (100, 50)。斜着设，清晰区会跟着倾斜，适合横穿画面的道路和铁轨。

操作顺序

一、先选对照片

至少从几米高处往下拍，俯角大概 30–60 度。广场、停车场、集市、铁路模型、沙滩伞阵。如果画面里有平视高度的地平线，这个效果就会像做错了。没有任何参数能救一张选错视角的照片。

二、把带放在主体上

X 起点 0、Y 起点 45–55、X 终点 100、Y 终点取同一个值，就得到一条横穿中部的清晰带。两个 Y 一起移动：往上多留前景，往下偏重远景。带要够窄，眼睛才分得清「哪里是对上焦的」。

三、先定模糊，再定过渡

模糊半径从 10、渐变半径从 70 起步。然后加模糊半径，直到失焦区明确地读作「没对上焦」——3000 像素的图，12–20 通常够，超过 25 就开始像滤镜而不像镜头。渐变半径决定过渡：数值小，清晰与模糊之间会出现一条看得见的线；数值大，更像真实的景深。

四、加颜色，别只加模糊

饱和度 5–8 就有玩具感。微缩模型的颜色本来比现实更亮更平，小幅提饱和正好对上这个预期。锐化留在 1–2，让清晰带比周围稍硬一点。

为什么有时看起来就是不对

  • 真实的尺度线索还在。 强透视、超大的前景物体、认得出的人脸，都会告诉大脑这是真实尺度，于是模糊就变成了画质缺陷。
  • 带没跟着地面走。 倾斜的街道上用水平带，近处路面清楚、远处路面模糊，没有哪支镜头会这样。
  • 模糊是均匀的。 真实失焦随距离递增。单一半径的模糊处处一样，半径一大，幻觉立刻塌。
  • 主体太大。 微缩感需要物体在画面里够小。一辆车占了三分之一画面，怎么都不可能像玩具。

一个更立体的变体

分两遍做，深度感会好很多：第一遍模糊半径 6、作用整幅；第二遍半径 20，只通过移动带把远处背景框进去。两种模糊强度叠起来读作「逐渐失焦」，而不是一个平面上的失焦，更接近真实移轴镜头的表现。

别用的场合

  • 人像、婚礼、商品图——效果会直接毁掉主体。
  • 带外还有必须可读的文字。糊掉的文字看起来像渲染错误。
  • 要大幅打印的照片：清晰与模糊的交界放大后会变成一条明显的渐变带。
💡 高处俯拍 + 窄水平带 + 模糊半径 12–20 + 渐变 70 以上 + 饱和 5–8。平视拍的照片，直接跳过这个效果。

常见问题

视角移位做出来为什么很假？

通常是照片平视拍的，或者主体在画面里太大。微缩模糊需要高角度、物体多而小的照片。另外检查清晰带有没有跟着地面走——在倾斜的街道上放一条水平带，会做出任何镜头都不可能产生的清晰度分布。

模糊半径和渐变该设多少？

3000 像素的图，模糊半径 12–20、渐变半径 70 以上。不超过 25 才像失焦而不像滤镜；渐变值大一些，过渡更软，看起来像景深而不是一条硬边带。

模糊效果为什么要加饱和度？

因为微缩模型的颜色比真实街道更亮更平，大脑会把鲜艳的颜色和玩具联系起来。饱和度 5–8 正好支持这个联想。不加的话，只是一张背景糊掉的照片。

联系我们

最近更新日期：2026年10月2日

每一封来信我们都会阅读。无论你是遇到了功能异常、想提出功能建议、需要确认授权范围，还是有商务合作方面的问题，本页面会告诉你最快的联系方式。

邮箱联系： support@webpseditor.com
支持中文与英文沟通，我们通常在 1–3 个工作日内 回复。

1. 邮箱是唯一的支持渠道

Web PSEditor 是一个独立的小型项目，没有工单系统，也没有客服电话。邮箱是唯一官方渠道，这样所有沟通都留存在同一份可检索的记录里，不会遗漏。为了让我们能一次性解决你的问题，请在邮件中尽量包含以下信息：

  • 你当时使用的具体页面或具体工具（例如"滤镜 → 锐化"或"魔棒选区"）。
  • 你的浏览器与操作系统版本（例如 Windows 11 上的 Chrome 128）。
  • 你期望的结果与实际发生的情况，简要描述即可。
  • 如果是界面显示类问题，请附带截图；发送前请先遮盖个人信息。

2. 我们能帮你处理的事项

  • Bug 反馈——工具行为异常、页面崩溃、渲染错误或导出失败。
  • 功能建议——告诉我们你缺少哪项编辑能力，以及你想用它完成什么。
  • 使用疑问——如何实现某个具体效果。教程中心已经覆盖了其中大部分内容。
  • 授权与署名——关于 MIT 许可证的问题，或在商业流程中使用 Web PSEditor 的相关咨询。
  • 隐私相关疑问——对图片、Cookie 或广告数据处理方式不清楚的地方。
  • 商务与广告合作——合作、赞助或媒体采访事宜。

3. 我们无法帮你处理的事项

为了不让你的期待落空，以下几类请求在技术上确实无法做到：

  • 找回丢失的图片或工程。 你的文件从不上传，我们这边没有任何副本可供恢复。请自行做好本地备份，并在编辑过程中定期保存 JSON 工程文件。
  • 代为编辑文件。 我们无法帮你打开、处理或交付修好的图片。
  • 修复浏览器或设备本身的问题。 由浏览器版本过旧、扩展插件干扰或磁盘空间不足引起的问题，需要在你的本地环境中解决。
  • 撤回已经导出的修改。 在结果令你满意之前，请务必保留原始文件。

4. 版权与内容投诉

如果你认为本网站可访问的内容侵犯了你的合法权益，请发送邮件说明：(a) 涉及作品的具体描述；(b) 该内容的确切访问位置；(c) 你代表权利人行事的相关声明。我们会审核每一份通知并及时回复。

需要说明的是，你在 Web PSEditor 中编辑的图片均在本地处理、我们从不存储，因此我们这边并不存在可供检索的用户内容库。

5. 回复时效

邮件按收到顺序处理，支持中文与英文。绝大多数邮件会在 1–3 个工作日内回复；需要复现的复杂 Bug 报告可能稍慢一些。如果超过一周仍未收到回复，欢迎在同一邮件线程中简短追问一次。

6. 写信之前

很多常见问题其实已有书面答案：具体修图流程见 使用教程，数据处理方式见 隐私政策，授权范围见 服务条款，工具原理见 关于我们。如果那里已经有答案，你就不必等待回信了。

使用教程与功能指南

最近更新日期：2026年9月20日

Web PSEditor 是一款轻量、免安装的高性能在线图像编辑工具。依托现代浏览器 HTML5 Canvas 技术，为您带来媲美桌面端图像处理软件的创作体验。

核心功能模块

图层管理与混合模式

支持多图层自由叠加、调整不透明度、修改图层顺序，并提供正片叠底、滤色、叠加等多种专业混合模式。

丰富的绘图与选区工具

涵盖魔棒选区、套索工具、矩形与椭圆选择、画笔、仿制图章、渐变填充及文本编辑工具。

滤镜与特效增强

内置高斯模糊、锐化、色彩平衡、曲线色阶调整、晕影、黑白胶片、移轴摄影等多种视觉滤镜。

本地零网络隐私保护

所有图像计算 100% 在本地设备内存中实时完成，不上传、不上云，最大化保障您的资产隐私安全。

四步快速上手

  1. 打开图片：点击顶部菜单 文件 → 打开，或直接将电脑上的图片拖拽至中间画布区域。
  2. 选择工具：在左侧工具箱中选择您需要的画笔、橡皮擦、裁剪、选区或魔棒工具。
  3. 精细调节：通过顶部菜单的 图像 与 效果 应用滤镜、色彩校正，并在右侧面板管理图层与图层属性。
  4. 导出成果：点击 文件 → 保存，支持导出 PNG（支持透明背景）、JPG、WEBP 格式或保存为方便二次修改的 JSON 工程文件。

User Guide & Overview

Last updated: September 20, 2026

Web PSEditor is a lightweight, responsive online image editor powered by HTML5 and Canvas. It provides powerful editing tools right in your web browser without requiring plugins or desktop installations.

Key Capabilities

Layers & Transparency

Full support for multiple layers, blend modes, opacity control, and layer sorting for complex graphic compositions.

Rich Toolset

Includes Selection, Magic Eraser, Brush, Pencil, Clone Tool, Gradient, Text, Color Picker, and Shape Drawing tools.

Image Effects & Filters

Sharpen, Blur, Vignette, Tilt Shift, Color Adjustments, Brightness/Contrast, Invert, Black & White, and Noise filters.

Privacy by Default

100% of calculations happen on your local device. Your pictures are never sent across the network or stored on remote servers.

How to Start

  1. Open Image: Click File → Open or drag-and-drop any image file directly into the browser canvas.
  2. Choose Tool: Select your desired tool from the left toolbar (e.g., Brush, Eraser, Crop, Text).
  3. Apply Effects: Use the top navigation bar to apply Filters, Layer adjustments, or Color transformations.
  4. Export: Click File → Save to export as PNG, JPG, WEBP, or save as a reusable JSON project file.

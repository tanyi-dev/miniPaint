🛠️ 基础界面与核心工具指南

1. 导入与新建画布

支持从电脑打开常用图片（JPG/PNG/WEBP/SVG/GIF 等），也可直接按 Ctrl+V 粘贴剪贴板中的截图开始修图。

2. 选区与抠图工具箱

提供矩形、椭圆选区、套索工具、魔棒工具（Magic Wand），支持容差调节与按住 Shift 连续追加选区。

3. 多图层与混合体系

支持无限图层叠加、自由调整不透明度、锁定图层、复制图层，以及正片叠底、滤色、柔光等几十种专业混合效果。

4. 丰富特效与滤镜

内置锐化、高斯模糊、色相饱和度调节、曲线、色阶、黑白转换、反色及马赛克像素化等主流调色滤镜。

⚡ 常用快捷键速查表

快捷键功能说明
Ctrl + Z撤销上一步操作 (Undo)
Ctrl + O打开本地图片文件
Ctrl + S保存并导出当前作品
Delete / Backspace删除当前选区内的像素内容
Ctrl + D取消当前选区
Space + 鼠标拖拽快速抓手平移画布
